# 🆘 Support / پشتیبانی

## 🇬🇧 English
- 📖 Start with the [README](README.md) and its **Troubleshooting** and **FAQ** sections
- 🐛 Found a bug? [Open a bug report](../../issues/new/choose)
- 💡 Have an idea? [Open a feature request](../../issues/new/choose)
- 🔒 Security problem? Use the private report in the **Security** tab — never a public issue

When asking for help, include your Ubuntu version, CS2 build and the relevant log (with tokens removed).

## 🇮🇷 فارسی
- 📖 ابتدا [README فارسی](README.fa.md) و بخش‌های **عیب‌یابی** و **سؤالات متداول** را ببینید
- 🐛 باگ پیدا کردید؟ [گزارش باگ بدهید](../../issues/new/choose)
- 💡 ایده دارید؟ [پیشنهاد قابلیت ثبت کنید](../../issues/new/choose)
- 🔒 مشکل امنیتی؟ از گزارش خصوصی در تب **Security** استفاده کنید، نه Issue عمومی

هنگام درخواست کمک، نسخهٔ Ubuntu، بیلد CS2 و لاگ مرتبط (بدون توکن) را بنویسید.
